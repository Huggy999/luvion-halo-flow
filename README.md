# Luvion Flow

Построй Luvion — мобильное веб-приложение для личной и командной продуктивности. Весь интерфейс на русском языке. Мобильный макет 430 px по центру экрана, на телефоне во всю ширину.

## ДИЗАЙН-СИСТЕМА (точные значения, не подбирай свои)

Светлая тема (основная):
--blue #027EFC (бренд, из логотипа) · --blue-btn #0A6BE0 (фон кнопок) · --blue-ink #0A57BE (синий текст)
--halo #FFC24D (золото, только серии и достижения) · --halo-tx #8A6300 (золото как ТЕКСТ)
--mint #22C495 / --mint-tx #0A7C58 · --coral #FF6B5A / --coral-tx #C13A28 · --lilac #8B7BF5 (только ИИ)
--ink #0A1223 · --ink-2 #46546E · --ink-3 #62708A
--paper #FFFFFF · --bg #F2F6FD · --line #E4ECF8 · --line-2 #D2DFF1

Тёмная тема — чёрно-золотая, переключается в профиле:
--bg #050609 · --paper #0C0F16 · --ink #F1ECE2 · --ink-2 #A6A092 · --ink-3 #8A8474
--line #1A1F2A · --line-2 #262D3B · --blue #3D9AFF · --halo #FFC24D · --halo-tx #FFD68A

ДВА ЖЁСТКИХ ПРАВИЛА ЦВЕТА, они выведены из расчёта контраста WCAG:
1. Бренд-синий #027EFC на белом даёт всего 3.89 — его НЕЛЬЗЯ использовать для мелкого текста. Только заливки, графика и крупный текст. Ссылки и подписи — #0A57BE, фон кнопок — #0A6BE0.
2. Золото #FFC24D на светлом даёт 1.61 — это краска, а не чернила. Золотой ТЕКСТ на светлом всегда #8A6300. В тёмной теме ограничение снимается.

Шрифты через Google Fonts: Unbounded (вес 300 — только заголовки экранов, 700 — акценты), Manrope (весь интерфейс: 400/500/700/800), JetBrains Mono (метки, числа, всегда font-variant-numeric: tabular-nums).
Радиусы: карточка 20, плитка 14, кнопка 15, чип 999, шторка 26.

## МАСКОТ ЛУМИ

Котёнок-ангел, рисуется одной непрерывной линией. Сделай React-компонент Lumi с вариантами idle / glow / think / sleep. Точный SVG, viewBox 0 0 100 100:
- нимб: <ellipse cx="50" cy="14" rx="23" ry="8.5" fill="none" stroke="#FFC24D" stroke-width="7"/>
- голова: <path d="M22 88C22 48 26 34 32 34c6 0 13 9 18 17 5-8 12-17 18-17 6 0 10 14 10 54" fill="none" stroke="currentColor" stroke-width="8" stroke-linecap="round"/>
- глаза: <circle cx="41" cy="66" r="4.6" fill="currentColor"/> и cx="59"
Вариант glow — вместо круглых глаз дуги-прищур: <path d="M34 62c2.5 3 5 3 7.5 0M58 62c2.5 3 5 3 7.5 0" stroke-width="5.5"/>
Вариант think — нимб пунктирный (stroke-dasharray "15 13") и вращается, это индикатор работы ИИ.
Вариант sleep — нимб тусклый и наклонён на -9°, глаза — горизонтальные чёрточки.
Голова всегда currentColor (обычно синяя), нимб всегда золотой.

## ГЛАВНАЯ МЕХАНИКА: НИМБ

Нимб — счётчик серии дней. Засчитывается за первую закрытую задачу календарного дня, пропуск дня обнуляет. Уровни: Искра 1–6, Луч 7–20, Свет 21–49, Маяк 50–99, Созвездие 100+. Храни рекорд.
Празднование при росте серии, 900 мс, три фазы: вспышка нимба → семь лучей расходятся и гаснут → число перекатывается на +1. Плюс разлёт золотых искр от числа.
Серию можно полностью выключить в профиле. Продукт не стыдит: потеря серии показывается тускло, а не красным.

## ЭКРАНЫ — нижний таб-бар из 5 вкладок, плавающий, скруглённый 22

1. ПУЛЬС — дата и заголовок, золотая карточка нимба с кольцом прогресса и Луми внутри, три счётчика (на сегодня / всего / закрыто), полоска недели с золотыми точками за засчитанные дни, «Сегодня в фокусе» со списком задач, сиреневая карточка Luvion AI.
2. ХАБЫ — список хабов с цветной плиткой-иконкой, прогрессом и счётчиком. Внутри хаба сегмент-контрол Задачи · Доска · Документы. Можно создать свой хаб с именем, описанием и цветом.
3. МОЙ ДЕНЬ — фокус-таймер 25 минут с кольцом и Луми в центре, идёт по-настоящему, счётчик сессий 1–4. Три задачи на сегодня и пул «добавить на сегодня».
4. ЛУМИ — чат ИИ-помощника. Отвечает по РЕАЛЬНЫМ задачам и хабам пользователя из базы, а не выдумывает. Нимб в шапке крутится пунктиром, пока он думает, и коротко вспыхивает золотом, когда ответ готов. Ответ — не пузырь мессенджера, а обычный текст с карточками-результатами. Подсказки-чипы под лентой.
5. ПРОФИЛЬ — уровень и рекорд серии, выбор темы, тумблеры Луми и серий, кнопка сброса данных.

ДОСКА: колонки Бэклог · В работе · Ревью · Готово, горизонтальная прокрутка с примагничиванием. Карточка двигается стрелками на ней самой. Перенос в «Готово» закрывает задачу и засчитывает день серии.

РЕДАКТОР ДОКУМЕНТОВ: блочный. Типы блоков — заголовок, абзац, чек-лист, выноска. Enter создаёт следующий блок, Backspace в пустом удаляет и возвращает курсор в предыдущий. Панель типов внизу применяется к блоку с курсором. Автосохранение, счётчик слов.

## ДОСТУПНОСТЬ — обязательные требования

- Поля ввода минимум 16px, иначе Safari на iOS зумит экран при фокусе.
- Цели касания минимум 44×44. Мелкие визуально элементы расширяй псевдоэлементом ::after, следи чтобы расширенные зоны соседей не перекрывались.
- Нижние элементы с отступом env(safe-area-inset-bottom).
- Модальная шторка: фон получает inert, фокус уходит внутрь, при закрытии возвращается на кнопку-триггер. Escape закрывает. aria-hidden на фон НЕ вешать.
- Все иконочные кнопки с aria-label. Тумблеры role="switch" с aria-checked, чекбоксы role="checkbox".
- Живая область aria-live="polite" объявляет закрытие задачи, перенос по колонкам и готовность ответа ИИ.
- Метки не мельче 11px. Уважай prefers-reduced-motion.

## МОУШЕН

Экран при смене вкладки въезжает каскадом: дети контейнера поднимаются на 14px со сдвигом 50 мс. Активная вкладка не перескакивает, а распускается пружиной. Галочка чекбокса прорисовывается по stroke-dashoffset, зачёркивание идёт слева направо. Кольцо нимба дышит свечением. Шторка выезжает пружиной. Каскад играет только при смене экрана, не на каждое изменение данных.

## ДАННЫЕ

Подключи базу и храни: хабы, задачи (заголовок, хаб, приоритет p1/p2/p3, статус колонки, флаг «на сегодня», выполнено), документы с блоками, серию, настройки, историю чата. Начальные данные: три хаба Продукт · Компания · Личное и четыре примерные задачи. Всё должно переживать перезагрузку.

Тон интерфейса: без эмодзи, без восклицательных знаков, без «Упс». Ошибка называет причину и следующий шаг. Успех обычного действия не требует уведомления.
